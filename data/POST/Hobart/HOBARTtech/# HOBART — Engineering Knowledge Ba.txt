# HOBART — Engineering Knowledge Base

## Core Engineering Principle

Cleaning efficiency defined by **Sinner Circle**

```
E = M × C × T × t
```

Variables

```
M = Mechanical action (pump pressure / spray pattern)
C = Chemical concentration (detergent / rinse aid)
T = Temperature
t = Time (cycle duration)
```

Sanitation requirement

```
Final rinse temperature: 82–84 °C
Surface sanitation temperature: ~71 °C
```

Standards

```
NSF/ANSI 3
NSF/ANSI 4
```

# Sensor Architecture

## Temperature Sensors

Type

```
NTC Thermistor
Nominal resistance: 100kΩ
```

Operating temperature range

```
10 °C – 115 °C
```

Resistance reference table

| Temperature °F | Temperature °C | Resistance |
| -------------- | -------------- | ---------- |
| 32             | 0              | 240–300 kΩ |
| 70–77          | 21–25          | 90–100 kΩ  |
| 120            | 49             | 35–40 kΩ   |
| 150            | 65             | 20 kΩ      |
| 165            | 74             | 13 kΩ      |

Sensor fault indicators

```

# Sequence of Operations

## AM16 Example

Initialization

```
Control board startup
Door interlock check (LS1)
Strainer interlock check (LS2)
```

Fill phase

```
Fill valve: SOL1
Water level detection: pressure sensor
```

Heating phase

```
Booster heater: HTR2
Activated after safe water level detection
```

Wash phase

```
Wash pump motor: MTR1
Cycle durations: 1 / 2 / 4 / 6 min
```

Dwell phase

```
2-second pause
```

Rinse phase

```
Rinse pump: MTR2
Fresh hot water rinse
```

Drain phase

```
Manual or automatic drain cycle
```

```

# Pressure Transducer Test

Input

```
Black wire → 5VDC supply
Ground → sensor ground
Signal → output mV
```

Expected behavior

```
Empty tank → baseline mV
Increasing water level → increasing mV
```

Failure indicators

```
No signal change
Blocked air trap
Sensor failure
```
