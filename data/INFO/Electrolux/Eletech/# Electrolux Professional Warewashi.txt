# 11. Hydraulic Fault Codes

| Code      | Problem                   | Diagnostic Path                 |
| --------- | ------------------------- | ------------------------------- |
| i10 / i11 | Water inlet failure       | check inlet valve, supply tap   |
| i20 / C2  | Drain error               | clean sump, inspect drain hose  |
| i30       | Leak detected             | inspect base tray, float switch |
| i40 / i43 | Pressure sensor fault     | clean air trap                  |
| i50       | Wash motor fault          | test pump motor, PCB triac      |
| iF0 / iF1 | Water level inconsistency | check siphoning                 |
